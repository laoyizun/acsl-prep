答案解析 1

数字系统 + 递归 4 题 详解

题 1-4 详解（完整手算）

题 1：5 个数哪个二进制 1 最多（答案 C. 255₁₀）

5 个数全部转 2 进制: 234₈ = 10011100₂ (4 个 1) AB1₁₆ = 101010110001₂ (6 个 1) 255₁₀ = 11111111₂ (8 个 1) ← 最多 300₁₆ = 1100000000₂ (2 个 1) 500₈ = 101000000₂ (2 个 1) 答案: C. 255₁₀ (8 个 1)

题 2：4 表达式最大（答案 c, 487）

全部转 10 进制: a) 456₈ + 10110110₂ = 302 + 182 = 484 b) 10110101₂ + 456₈ = 181 + 302 = 483 c) 460₈ + 10110111₂ = 304 + 183 = 487 ← 最大 d) 10110100₂ + 454₈ = 180 + 300 = 480 答案: c (487)

题 3：f(6) 基础递推（答案 A. 157）

f(1) = 2 f(2) = 2·f(1) + 3 = 2·2 + 3 = 7 f(3) = 2·f(2) + 3 = 2·7 + 3 = 17 f(4) = 2·f(3) + 3 = 2·17 + 3 = 37 f(5) = 2·f(4) + 3 = 2·37 + 3 = 77 f(6) = 2·f(5) + 3 = 2·77 + 3 = 157 答案: A. 157

题 4：f(f(f(5))) 多分支（答案 B. 32）

函数（L5 自编）: f(x) = 5 if x ≤ 2 f(x) = f(x-2) + 3 if x 是偶数 f(x) = f(x-1) + 4 if x 是奇数 且 x > 2 调用树（剥洋葱）: f(f(f(5))) = f(f(12)) = f(20) 算 f(5) 走奇数分支: f(5) = f(4) + 4, f(4) = f(2) + 3 = 5 + 3 = 8 f(5) = 8 + 4 = 12 算 f(12) 走偶数分支: f(12) = f(10) + 3 f(10) = f(8) + 3 f(8) = f(6) + 3 f(6) = f(4) + 3 = 8 + 3 = 11 f(8) = 11 + 3 = 14 f(10) = 14 + 3 = 17 f(12) = 17 + 3 = 20 算 f(20) 走偶数分支: f(20) = f(18) + 3 f(18) = f(16) + 3 f(16) = f(14) + 3 f(14) = f(12) + 3 = 20 + 3 = 23 f(16) = 23 + 3 = 26 f(18) = 26 + 3 = 29 f(20) = 29 + 3 = 32 ← 答案 B

错因分析

常见 错因

避免这些错 · 12.13 拿 6/6

5 大常见错因

  • 进制转换忘分组：8↔2 用 3 位，2↔16 用 4 位
  • 递归跳步：f(15) 忘了先 f(13)
  • 追踪表漏一列：4 变量必须 4 列
  • 整数除法当浮点：7/2 = 3，不是 3.5
  • 表达式优先级：a+b·c ≠ (a+b)·c
