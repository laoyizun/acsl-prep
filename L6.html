为什么要有三种写法

同一个算式 三种顺序

看的是同一个东西

以 3 + 4 * 2 为例（三者值都 = 11）

中缀 Infix ：3 + 4 * 2 ← 我们平时写的 前缀 Prefix ：+ 3 * 4 2 ← 运算符在前 后缀 Postfix ：3 4 2 * + ← 运算符在后

为什么要换？

  • 中缀有歧义：3 + 4 * 2 到底先算哪个？得靠优先级 + 括号
  • 后缀/前缀没有歧义：不需要优先级，不需要括号
  • 计算机更好算：一个栈就能求值，不用反复回看

小例子：括号消失了吗？

中缀：(2 + 3) * 4 = 20 后缀：2 3 + 4 * = 20 ← 括号没了，顺序却记住了
小贴士

后缀 = 运算符在操作数后面，记住这一句就够了

怎么一眼看出对不对？

  • 后缀：运算符出现时，它前面紧挨着的两个数就是它的操作数
  • 前缀：运算符出现时，它后面紧挨着的两个表达式就是它的操作数
  • 中缀：优先级 * / > + -，同级从左往右

方法 1

中缀 → 后缀 栈模拟

考场上要能手工推出来

两个栈

  • 输出栈：放操作数（数字/字母）
  • 运算符栈：放 + - * /

5 条规则

  1. 遇到操作数 → 直接丢进输出栈
  2. 遇到运算符 → 先把栈顶优先级≥ 它的全弹进输出，再把它压栈
  3. 遇到 ( → 压运算符栈（不弹）
  4. 遇到 ) → 弹到 ( 为止，( 本身丢掉
  5. 全部读完 → 把运算符栈全部弹完

⚠️ 最容易错的地方

  • 规则 2 用的是 ≥ 不是 >（同级也要先弹）
  • 规则 4 里 ( 要丢掉，不能进输出
  • 规则 5 别忘了弹，漏一个运算符答案就错

方法 2

中缀 → 前缀

前缀 = 运算符在前

核心思想：前缀 = 后缀「整体倒过来 + 每个运算符移到前面」

更简单的办法是先转后缀，再倒序，然后每个运算符「插到它那一段的最后面」——但考场上更实用的是这招：

实战：3 + 4 * (8 − 4 / 2)

步骤 1：从里往外包。整式的运算是 + → 先把括号里的 4 * (8 − 4/2) 包起来 步骤 2：括号内运算是 * → 把 8 − 4/2 包起来 步骤 3：括号内运算是 − → 把 4 / 2 包起来 从内到外写前缀： (1) 4 / 2 → / 4 2 (2) 8 − (1) → − 8 / 4 2 (3) 4 * (2) → * 4 − 8 / 4 2 (4) 3 + (3) → + 3 * 4 − 8 / 4 2

记忆法

从最里层的括号开始，把那一层「运算符 + 左 + 右」拼起来，然后往外一层层包。

小贴士

官方答案就是 B：+ 3 * 4 − 8 / 4 2

方法 3

后缀 求值

一个栈，从左往右扫

2 条规则

  • 遇到数字 → 压栈
  • 遇到运算符 → 弹出两个数，先弹的是右操作数，后弹的是左操作数，算完压回

演示：3 4 2 * +

读 3 → 压栈 [3] 读 4 → 压栈 [3, 4] 读 2 → 压栈 [3, 4, 2] 读 * → 弹 2 和 4 4 × 2 = 8 压回 [3, 8] 读 + → 弹 8 和 3 3 + 8 = 11 压回 [11] 最后栈里剩一个数 → 11

⚠️ 减法的陷阱

10 3 − 要算成 10 − 3 = 7，不是 3 − 10。
先弹的是右操作数，后弹的是左操作数，顺序反了就错。

小贴士

整个过程从头到尾一个栈，不用管优先级，不用管括号

方法 4

前缀 求值

跟后缀一样，只是方向反过来

规则

  • 从右往左扫
  • 遇到数字 → 压栈
  • 遇到运算符 → 弹两个数，先弹的是左操作数，后弹的是右操作数

演示：+ 3 * 4 2（从右往左）

读 2 → 压栈 [2] 读 4 → 压栈 [2, 4] 读 * → 弹 4 和 2 4 × 2 = 8 压回 [8] 读 3 → 压栈 [8, 3] 读 + → 弹 3 和 8 3 + 8 = 11 压回 [11] 答案：11

⚠️ 前缀 vs 后缀的唯一区别

类型扫描方向先弹的是
后缀左 → 右右操作数
前缀右 → 左左操作数

题目

将中缀表达式转成后缀：

(A+B)/(C-1) + (2A-3)/D
A. AB+C1−/2A3*−D/+
B. AB+C1−/2A*3−D/+
C. ABC1−+/2A*3−D/+
D. AB+C1−/2A*3−D+/

点这里看答案 + 分块拆解

答案：B. AB+C1−/2A*3−D/+

分块拆解（先拆成 4 块，再各自转后缀）：

块 1: (A+B)/(C-1) → A B + C 1 − / 块 2: (2A-3)/D → 2 A * 3 − D / 整式: 块1 / 块2 + → 块1 块2 / + 拼起来： A B + C 1 − / 2 A * 3 − D / +

怎么防止选错：

  • A 选项：2A3 错了，2A-3 应该是 2A*3-
  • C 选项：(C-1) 错写成 (C1-)，减法顺序反了
  • D 选项：最后的 + 和 / 顺序反了
  • E 选项：3D 错了

求前缀式值

2023-2024 真题第 1 题

题目

求下列前缀表达式的值（所有数字都是一位数）：

− + 2 * 3 8 / * 6 2 3
A. 12
B. 20
C. 22
D. 25
E. 30
点这里看答案 + 完整推演

答案：C. 22

方法一 · 画树（推荐，最不容易错）

− 根 = 减法 ├─ 左: + 2 * 3 8 → 2 + (3×8) = 26 │ ├─ 左: 2 │ └─ 右: * 3 8 → 3×8 = 24 └─ 右: / * 6 2 3 → (6×2)÷3 = 4 ├─ 左: * 6 2 → 6×2 = 12 └─ 右: 3 26 − 4 = 22

方法二 · 栈模拟（从右往左）

逆序读：3 2 6 * / 8 3 * 2 + − 读 3 → [3] 读 2 → [3, 2] 读 6 → [3, 2, 6] 读 * → 左6 右2 → 12 [3, 12] 读 / → 左12 右3 → 4 [4] 读 8 → [4, 8] 读 3 → [4, 8, 3] 读 * → 左3 右8 → 24 [4, 24] 读 2 → [4, 24, 2] 读 + → 左2 右24 → 26 [4, 26] 读 − → 左26 右4 → 22 [22]

易错：逆序读的时候，/ 紧跟在 * 后面，读到 / 时栈里只有 [3, 12]（不是 3 个数）。不要跳着读，一个 token 一个 token 读。

方法 4 · 加深理解

前缀求值 为什么容易错

和后缀的唯一区别

两个坑

  • 坑 1 · 扫的方向反了：前缀必须从右往左扫，扫成从左往右就全错
  • 坑 2 · 弹的顺序反了：前缀先弹的是左操作数，后缀才是右操作数

同一个式子，三种算法，结果必须一样

表达式：3 + 4 * 2 = 11 中缀： 3 + 4 * 2 = 3 + 8 = 11 前缀： + 3 * 4 2 从右扫 2 → 4 → * → 8 → 3 → + → 11 后缀： 3 4 2 * + 从左扫 3 → 4 → 2 → * → 8 → + → 11

前缀求值的可靠做法

  • 先数一下运算符个数，确定树有几层
  • 再从左往右切出子树（左子树要先能配平）
  • 最后自底向上算，或直接从右往左推栈

表达式题 6 大坑

6 个高频错点

  1. 栈规则用 > 而不是 ≥ → 同优先级运算顺序错
  2. 括号 ( 忘了丢掉 → 输出里多了一个括号
  3. 读完全忘了弹栈 → 后缀表达式末尾缺运算符
  4. 后缀减法弹反了 → 算成右−左
  5. 隐式乘 2A 没展开 → 漏掉 *
  6. 整数除法当小数 → 8/3 应为 2 不是 2.67

3 个保命习惯

  • 转换题先分块：把长式子按括号拆成 3-4 小块
  • 求值题先画树：前缀尤其容易配错
  • 算完代回验算：结果代回原式对不对
