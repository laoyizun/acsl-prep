考场上 手算用除法，2↔8/16 用分组，8/16 → 10 用加权

16 进制加法

16 进制 加法

字母 A=10, B=11, C=12, D=13, E=14, F=15

规则

个位相加 ≥ 16 时进 1，余数写当前位置

例：9876₁₆ + ABC₁₆ = ?

9 8 7 6₁₆ + A B C₁₆ --------- A 3 3 2₁₆ 竖式： 6 + C = 6 + 12 = 18 = 2 进 1 7 + B + 1 = 7 + 11 + 1 = 19 = 3 进 1 8 + A + 1 = 8 + 10 + 1 = 19 = 3 进 1 9 + 0 + 0 = 9

答案：A332₁₆

小贴士

进位用"≥16 进 1"，和 = 和-16，结果写 (和-16) 并进位

跨进制转换

8 ↔ 16 走 2 进制

2 进制是"通用货币" · 任何进制间转换都走它

例：657383₁₆ − 654321₁₆ = ?₈

657383₁₆ − 654321₁₆ = 3062₁₆ 3062₁₆ = 0011 0000 0110 0010₂ = 11 000 001 100 010₂ = 30142₈ ← 3 位一组

答案：30142₈

走 2 进制的优势

  • 8/16 间转换：先 16→2，再 2→8（每 3 位 1 组）
  • 避免心算8/16 间直接的位对应（容易错位）
  • 分组对齐用 0 补齐高位（左补 0）
小贴士

8/16 间转换走 2 进制，比加权快 10 倍

递归 · 调用树

递归 怎么算？

L2 已学：调用树 = 向下展开 + 向上回填

调用树模板

f(5) ← 顶层 └─ f(4) ← 等待 └─ f(3) ← 等待 └─ f(2) ← 等待 └─ f(1) = 2 ← base case 命中 ↑ 2 + 2 = 4 ↑ 4 + 3 = 7 ↑ 7 + 4 = 11 ↑ 11 + 5 = 16 ← 最终结果

3 步法

  1. 画调用树（向下展开到 base case）
  2. 从 base case 回填（向上算每层）
  3. 写到目标层就是答案
小贴士

先画调用树（向下展开），再从 base case 向上回填

分段递归 Piecewise

分段 递归

真考高频考点 · 2022-2023 / 2023-2024 / 2024-2025 都有

什么是分段递归？

f(x) 在不同 x 范围用不同公式：

f(x) = { f(x - 3) + 1 if x > 9 f(x - 2) - 3 if 5 < x ≤ 9 25 if x ≤ 5 }

3 步法（每次递归前）

  1. 看 x 在哪个段（> 9? 5-9? ≤ 5?）
  2. 用对应公式递归
  3. base case 一旦命中立刻返回
小贴士

每一步递归前 先判断 x 落在哪个分支，别上来就套公式

分段递归例题

区间分段 f(12)

2022-2023 真题函数：x≤5 / 59

追踪

f(12) → 12 > 9, f(x-3)+1 = f(9) + 1 f(9) → 5 < 9 ≤ 9, f(x-2)-3 = f(7) - 3 f(7) → 5 < 7 ≤ 9, f(x-2)-3 = f(5) - 3 f(5) → 5 ≤ 5, base = 25 回填： f(5) = 25 f(7) = 25 - 3 = 22 f(9) = 22 - 3 = 19 f(12) = 19 + 1 = 20

答案：f(12) = 20

易错点

  • 边界条件：x=5 时是 base case（不是"5
  • 别跳步：f(12) 算完 9，再算 7，再算 5（base）
  • 注意符号：第二段是 -3，第三段是 +1，不要混
小贴士

分段递归看清区间边界（≤ / <）和符号（+/-）

整数除法 + 赋值

整数除法 易错点

ACSL 默认整数除法 · 7/2 = 3，不是 3.5

3 个易错点

  • 整数除法：7 / 2 = 3（不是 3.5）
  • 指数：2 ^ 3 = 8（不是 6）
  • 赋值链：x = y + z; z = y - x （用新 x，不是原 x）

例：2024-2025 真题第 5 题

x = 8 y = 9 z = -2 x = y + z → x = 7 （用旧 y=9, z=-2） z = y - x → z = 2 （用新 x=7） y = y + 1 → y = 10 （用旧 y=9） output x, y, z → 7, 10, 2

答案：E. 7, 10, 2

真题 4 · 递归

奇偶分段 f(f(24)) = ?

来源：ACSL 2023-2024 Contest 1 Junior · 5 min 限时

题目

f(x) = f(x/2) + 4 if x 是偶数 f(x) = f(x-1) + 2 if x 是奇数 f(1) = 1 base f(9) = 9 base 求 f(f(24)) = ? （注意：1 不是质数）
A. 21
B. 19
C. 15
D. 11
E. 9
点这里看答案 + 完整手算过程

答案：C. 15

手算过程（先算 f(1..12)，再算 f(24) 和 f(19)）：

f(1) = 1 (base) f(2) = f(1) + 4 = 5 (偶) f(3) = f(2) + 2 = 7 (奇) f(4) = f(2) + 4 = 9 (偶) f(5) = f(4) + 2 = 11 (奇) f(6) = f(3) + 4 = 11 (偶) f(7) = f(6) + 2 = 13 (奇) f(8) = f(4) + 4 = 13 (偶) f(9) = 9 (base) f(10) = f(5) + 4 = 15 (偶) f(11) = f(10) + 2 = 17 (奇) f(12) = f(6) + 4 = 15 (偶) f(24) = f(12) + 4 = 19 f(18) = f(9) + 4 = 13 f(19) = f(18) + 2 = 15 f(f(24)) = f(19) = 15 ← 答案

真题 6 · 程序追踪

4 段代码 识别正确

来源：ACSL 2023-2024 Contest 1 Junior · 5 min 限时

题目

按时薪结算的工作，超过 40 小时按 1.5 倍计算。下列哪几段代码能正确计算工资？

a) if hrs > 40 then pay = (hrs-40) * rate * 1.5 + hrs * rate else pay = hrs * rate end if b) pay = hrs * rate if hrs > 40 then pay = pay + (hrs-40) * rate * 0.5 end if c) if hrs > 40 then pay = (hrs-40) * rate * 0.5 + hrs * rate else pay = hrs * rate end if d) pay = 40 * rate if hrs > 40 then pay = pay + 1.5 * (hrs - 40) * rate end if
A. a, b, c
B. a, c, d
C. b, c, d
D. a, c
E. b, c
点这里看答案 + 逐段分析

答案：E. b, c

逐段分析：

  • a 错：(hrs-40)·rate·1.5 是 1.5 倍加班费 + hrs·rate 是全工资 = 加班算 2.5 倍（实际只要 1.5 倍）
  • b 对：先算 hrs·rate 全工资，加班时 + (hrs-40)·rate·0.5 = 0.5 倍补差 → 总共 1.5 倍 ✓
  • c 对：同 b 但分两个 if（先算 hrs·rate，加班时 + 0.5 倍）→ 1.5 倍 ✓
  • d 错：hrs<40 时 pay=40·rate 多算（<40 小时不工作也给 40 小时钱）

答案：b, c → E
