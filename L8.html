📐 一个通用骨架

9 年真题几乎都是这个套路：

  1. 先把循环变量想清楚：1 to n？1 to n step 2？n to 1 step -1？
  2. 算循环次数（这一步最常错）
  3. 每一轮哪些变量会变 —— 列出来
  4. 最后取要输出的那个变量在最后一轮的值

L3 教了「画追踪表」，但真题的坑在于变量不止一个，而且会被循环体自己改写。

⚠️ L3 的 4 个空白

  • 循环变量被循环体改写
  • 循环体修改计数器自身
  • WHILE 条件一开始就不成立
  • 两个循环串联筛选（交集 ≠ 并集）

这 4 条就是 L8 要补的。

基础工具

循环次数 · 先算这个

90% 的追踪错误都出在「循环跑了几遍」上

🔢 次数速算表

写法跑几次说明
FOR i = 1 TO 551,2,3,4,5
FOR i = 1 TO 5 STEP 231,3,5（≤5 的等差）
FOR i = 3 TO 1 STEP -133,2,1
FOR i = 3 TO 1 STEP 10⚠️ 起点 > 终点，一次都不跑
FOR i = 2 TO 10 STEP 252,4,6,8,10
FOR k = 2 TO dd − 1k 从 2 数到 d
先算次数，再填表

追踪表最常见的死法是手滑多写一行。先在心里算出「这循环跑 N 次」，表就画不歪。

⚠️ 3 个边界情形

  • 起点 > 终点 → 循环体一次都不执行（FOR i = 3 TO 1 STEP 1）
  • 终点恰好落在步长上 → 要算进去（FOR j = 2 TO 10 STEP 2 跑 5 次，不是 4 次）
  • 步长为负 → 起点必须 > 终点（FOR z = 3 TO 1 STEP -1 ✓，FOR z = 1 TO 3 STEP -1 ✘）

🧮 快速验证法

次数 = ⌊(终点 − 起点) / 步长⌋ + 1（终点 ≥ 起点时）

验算 FOR j = 2 TO 10 STEP 2：
⌊(10−2)/2⌋ + 1 = 4 + 1 = 5 ✓

强化点 1

变量 被循环体改写

陷阱类型 ① · 欧几里得算法（2024-2025 真题原形）

m = 50 n = 40 while n != 0 r = m % n m = n n = r end while output m

📋 追踪表

步骤mn r说明
进入循环前5040—n ≠ 0 ✓ 进入
第 1 轮 r = m % n50401050 ÷ 40 = 1 余 10
第 1 轮 m = n404010m 改成 40
第 1 轮 n = r401010n 改成 10
第 2 轮 r = m % n4010040 ÷ 10 = 4 余 0
第 2 轮 m = n10100m 改成 10
第 2 轮 n = r1000n 改成 0
判断 n ≠ 01000n = 0 ✘ 退出循环
output m1000输出 10

⚠️ 坑在哪

m = n 这一行把 m 改掉了，下一行 n = r 用的是新的 m吗？

不是。 n = r 用的是 r，而 r 是上一轮就算好的，跟 m 无关。

如果你按「r = m % n 用新 m」去算，就会算错。

✅ 正确读法

  • r = m % n —— 用本轮开始时的 m 和 n
  • m = n —— m 变成 n 的旧值
  • n = r —— n 变成 r（r 刚算出来）
  • 所以这是交换：m 取 n 的旧值，n 取余数
一句话记住

追踪表里每写一行就更新一次，绝不用「这轮开始时的值」去套所有行。

强化点 1 · 真题

2024-2025 第 5 题 · 变量交换

官方答案 D. 10

真题 · 2024-2025 Q5
m = 50
n = 40
while n != 0
  r = m % n
  m = n
  n = r
end while
output m
问：程序输出什么？（A.50 B.40 C.20 D.10 E.0）
展开答案 · Show Answer
m = 50 n = 40 while n != 0 r = m % n m = n n = r end while output m

答案：10（D）

这就是辗转相除法求最大公约数：
GCF(50, 40) = GCF(40, 10) = GCF(10, 0) = 10

官方解析原话："This is Euclid's algorithm that finds the GCF in 2 iterations of the loop."

📋 手算追踪

退出1000n = 0 ✘

⚠️ 干扰项分析

  • A. 50 —— 只跑了 1 轮就停
  • B. 40 —— 误以为 m ← n 后就输出
  • C. 20 —— 把 50 % 40 算成 30 之类的乱数
  • E. 0 —— 误以为输出的是 n（最后一次 n = 0）
强化点 2

循环体 修改计数器自身

陷阱类型 ② · 复利计算（2022-2023 真题原形）

p = 1000, r = 10, t = 3 o = p for c = 1 to t i = p * r / 100 p = p + i next c f = p - o output f

📋 追踪表

轮次ip o说明
初始100010—o = p = 1000（快照）
c = 1i = 1000×10/100 = 100p = 1000+100 = 1100100p 变了
c = 2i = 1100×10/100 = 110p = 1100+110 = 1210110用新的 p 算 i
c = 3i = 1210×10/100 = 121p = 1210+121 = 1331121第 3 年
f = p − o1331——1331 − 1000 = 331
output f331——输出 331

⚠️ 坑在哪

i = p * r / 100 里的 p，是这一轮已经更新过的 p，不是循环开始时的 p。

第 2 轮要用 1100 算利息（110），而不是 1000（100）。

算成 1000+100、1100+100、1200+100 就全错了。

✅ 记住「自增型」

只要看到 p = p + ... 这类写法，p 就是逐轮累变的。

追踪表要一行一行往下滚，不能「算一次用到底」。

🔍 o = p 的作用

在循环之前把 p 的初始值 1000 存进 o（快照）。

最后 f = p - o 就是「终值 − 初值」= 利息。
如果忘了存这个快照，题目就没法算了。

强化点 3

WHILE 的 三种退出情形

陷阱类型 ③ · 判断时机（2023-2024 真题原形）

🔀 三种情形

情形示例循环体跑几次
① 条件一开始就假WHILE 0 < 10 次
② 跑够次数才假WHILE i < 54 次（i=1..4）
③ 跑着跑着变假WHILE t < d（d 也在变）看表

FOR 是「跑够就停」，WHILE 是「条件假就停」 —— 循环体内的变量变化会影响退出时机。

🧭 WHILE 追踪的正确姿势

  1. 先把循环体从上到下算一遍，得到新的 t
  2. 回到循环开头重新判断条件
  3. 条件为假 → 跳出，不要再执行一次循环体
  4. 最后一行的值就是输出

⚠️ 最常见的错

很多同学把 WHILE 的表少写一行 —— 只写到「条件变假」就停，忘了条件变假那一轮已经执行过了。

正确：先执行，再判断。所以最后一行的值是最后一次执行后的值。

对比记忆

FOR：先定循环变量 → 循环 N 次 → 结束
WHILE：先判条件 → 执行 → 再判 → 可能一次都不执行

💡 浮点数比较

2023-2024 用的是小数（.01 / .02 / .03…）。手算时保留 2 位小数，不要写成分数或化成百分比 —— 对齐小数点最不容易错。

强化点 4

嵌套循环 + 整除判断

陷阱类型 ④ · INT() 的用法（2016-2017 / 2021-2022 真题原形）

t = 0 for j = 1 to 5 for k = 1 to 5 for m = 1 to 5 if j*j + k*k = m*m then t = t + 1 next m next k next j t = t / 2 print t

📋 追踪表（只列出命中和典型行）

jkm判断t
1111+1=2 ≠ 10
1121+1=2 ≠ 40
3459+16 = 25 = 5² ✓1
43516+9 = 25 = 5² ✓2
53425+9 = 34 ≠ 162
———t = 2t = 2/2 = 1

⚠️ 坑 1：INT() 是整除判断

N / B = INT(N / B) → 判断 N 能不能被 B 整除。

INT(7/2) = INT(3.5) = 3，7/2 = 3.5 → 不相等，说明不能整除。
INT(8/2) = 4，8/2 = 4 → 相等，能整除。

✅ 坑 2：嵌套的顺序

三层循环 = 5 × 5 × 5 = 125 种组合。

但勾股三元组只有 (3,4,5) 一组，而且 (3,4,5) 和 (4,3,5) 都算 → t = 2。
所以最后要 t = t / 2 除掉重复。

技巧

125 种组合不要手算 —— 先猜答案范围，再用排除法验证，效率高得多。

真题 · 串行循环

2018-2019 第 5 题 · 4 个循环接力

强化点 5

两个循环 串联筛选

陷阱类型 ⑤ · 交集不是并集（2019-2020 真题原形）

INPUT N FOR B = 3 TO N - 1 STEP 2 IF N / B = INT(N / B) THEN GOTO notprime NEXT B FOR I = 1 TO 20 IF N == 2 ^ I - 1 THEN PRINT N END IF NEXT I notprime: END

📋 两个循环各筛一遍

B 循环：从 3 到 N−1 试奇数，找得到能整除 N 的 → N 不是质数，跳过
I 循环：N = 2I − 1 吗？是就 PRINT N

⚠️ 坑在哪

两个条件是「且」不是「或」！

必须既是质数，又是 2I−1 才会打印。

我自己第一次做就把这题算成了 5 个（5, 7, 31, 101, 127）—— 那是「或」。
正确答案是 3 个。

INPUT N

  IF N/B = INT(N/B) THEN GOTO notprime
NEXT B

  IF N == 2^I - 1 THEN
    PRINT N

官方答案 A. 24

真题 · 2024-2025 Q6
s = 0
for y = 2 to 8 step 2
  s = s + y / 2
next y
for z = 3 to 1 step -1
  s = s + z ^ 2
next z
output s
问：程序输出什么？
（A.24 B.23 C.22 D.20 E.10）
展开答案 · Show Answer
s = 0 for y = 2 to 8 step 2 s = s + y / 2 next y for z = 3 to 1 step -1 s = s + z ^ 2 next z output s

答案：24（A）

第一段 for y = 2 to 8 step 2：y = 2, 4, 6, 8
→ s = 1 + 2 + 3 + 4 = 10

第二段 for z = 3 to 1 step -1：z = 3, 2, 1
→ s = 10 + 9 + 4 + 1 = 24

官方解析："This program finds the sum of the numbers generated by the 2 loops."

📋 手算追踪

轮次第一段 第二段s
y = 2s = 0 + 2/2 = 1—s = 1
y = 4s = 1 + 4/2 = 3—s = 3
y = 6s = 3 + 6/2 = 6—s = 6
y = 8s = 6 + 8/2 = 10—s = 10
z = 3—s = 10 + 3² = 19s = 19
z = 2—s = 19 + 2² = 23s = 23
z = 1—s = 23 + 1² = 24s = 24
output——输出 24

✅ 关键

step -1 从 3 往下走到 1，走 3 次（3, 2, 1），不能漏掉 z = 1。

漏掉 z = 1 → 24 − 1 = 23（就是选项 B）！

  • C. 22 —— 两处都漏

  • E. 10 —— 只算了第一段
真题 · 三循环计数

2015-2016 第 5 题 · 三个循环各数一半

官方答案 36, 89 · 唯一一个输出两个数的

真题 · 2015-2016
C = 0 : S = 0
FOR I = 1 TO 50
  IF I/2 = INT(I/2) THEN C = C + 1 ELSE S = S + 1
NEXT I
FOR K = 1 TO 50
  IF (K/3 = INT(K/3)) AND (K/2 <> INT(K/2))
  THEN C = C + 1 ELSE S = S + 1
NEXT K
FOR J = 1 TO 50 STEP 2
  IF (J/5 = INT(J/5)) AND (J/3 <> INT(J/3))
  THEN C = C + 1 ELSE S = S + 1
NEXT J
PRINT C, S
问：程序打印什么？（两个数，用逗号分隔）
展开答案 · Show Answer
C = 0 : S = 0 FOR I = 1 TO 50 IF I/2 = INT(I/2) THEN C = C + 1 ELSE S = S + 1 NEXT I FOR K = 1 TO 50 IF (K/3 = INT(K/3)) AND (K/2 <> INT(K/2)) THEN C = C + 1 ELSE S = S + 1 NEXT K FOR J = 1 TO 50 STEP 2 IF (J/5 = INT(J/5)) AND (J/3 <> INT(J/3)) THEN C = C + 1 ELSE S = S + 1 NEXT J PRINT C, S

答案：36, 89

三个循环一共检查了 50 + 50 + 25 = 125 个数
每个数要么计入 C（能被整除），要么计入 S（不能）
所以 C + S = 125

① C 数2 的倍数（1~50 共 25 个）→ C = 25
② C 再加3 的倍数但不是 2 的倍数：3, 9, 15, 21, 27, 33, 39, 45（共 8 个）→ C = 33
③ C 再加5 的倍数但不是 3 的倍数（且是奇数）：5, 25, 35（共 3 个）→ C = 36
S = 125 − 36 = 89

官方解析："This program counts the integers from 1 to 50 inclusive that are divisible by 2, 3 or 5. There are 36 such integers. S counts the ones that are not, which is 89 since 125 integers were checked in the three loops."

📋 三个循环各数了什么

循环范围条件个数C 累计
① I1~50I/2 = INT(I/2)（偶数）2525
② K1~503 的倍数 且 不是 2 的倍数833
③ J1~50 step 25 的倍数 且 不是 3 的倍数336

✅ 神算技巧

不用真去数 125 个数！

① 三个循环一共检查 125 个（50+50+25）
② 每个数必然落进 C 或 S 之一 → C + S = 125
③ 只要算出 C，S = 125 − C 就有了

⚠️ 注意

第 ③ 个循环是 STEP 2 —— 只看奇数，所以只有 25 个数，不是 50 个。
