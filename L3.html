🆕 ACSL Pseudocode Syntax

ACSL 伪代码语法 · Python 对照

ACSL 用伪代码，不是 Python
ACSL uses pseudocode, not Python

5 个关键对照

ACSL 伪代码 Python 等价
INPUT xx = input()
OUTPUT xprint(x)
FOR j = 0 TO 9 STEP 1 ... NEXT jfor j in range(0, 10, 1):
WHILE ... END WHILEwhile ...:
IF ... THEN ... ELSE ... END IFif ... else ...

5 个常见陷阱 ⚠️

  1. 数组下标从 0 开始（不是 1）
  2. STEP -1 倒序（Python 用 range(n-1, -1, -1)）
  3. MOD 是取模（Python 用 %）
  4. S[2:6] 切片含头不含尾，长度 = 6-2 = 4
  5. ACSL 用 AND / OR / NOT，不用 && / || / !
📌 小贴士

ACSL 伪代码 = Python 简化版。语法不同但思想一样。

⚠️ 5 Common Pitfalls · 5 大陷阱

5 大陷阱 · 避免 ACSL 高频错点

考前必看
Must-review before exam

陷阱 1 · 循环变量递增

FOR j = 0 TO 9 时 j 自动 +1，别手动写 j = j + 1

❌ FOR j = 0 TO 9 j = j + 1 ← 错！会跳过值 OUTPUT j NEXT j ✅ FOR j = 0 TO 9 OUTPUT j ← 对！j 自动管理 NEXT j

陷阱 2 · STEP -1 起点

FOR j = N-1 TO 0 STEP -1，起点是 N-1，不是 N

A = [3,7,1] N=3 FOR j = 2 TO 0 STEP -1 ✓ OUTPUT A[j] → 1, 7, 3 FOR j = 3 TO 0 STEP -1 ✗ 越界 OUTPUT A[j] → 报错

陷阱 3 · 哨兵退出条件

WHILE A[k] > 0 是 > 0 不是 ≥ 0

A = [3, 5, 0, 7] i = 0; sum = 0 WHILE A[i] > 0 ← 0 不进 sum = sum + A[i] i = i + 1 END WHILE → sum = 8, 不会加 0 和 7

陷阱 4 · ACSL 切片

S[2:6] 第 2 个字符（含）到第 5 个字符（含），长度 = 6-2 = 4

S = "ACSL CAT" 索引: 0 1 2 3 4 5 6 7 S[2:6] = "SL C" ← 索引 2,3,4,5 长度 = 4 ❌ S[2:6] = "ACSL"（错 6 字符）

陷阱 5 · 嵌套循环变量

内层变量每次外层都要重置，但累加器（sum, n）保持延续

FOR i = 1 TO 3 FOR j = 1 TO i ← j 每次重置 OUTPUT i * j NEXT j NEXT i i=1: j=1 → 1 i=2: j=1,2 → 2, 4 ← j 重置为 1 i=3: j=1,2,3 → 3, 6, 9 ← j 重置为 1
