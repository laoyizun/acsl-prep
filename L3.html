第 1 章 · 续

循环语法 · Loops

WHILE / FOR ... NEXT —— 比 Python 严格

不定循环 · WHILE

WHILE A(k) > 0
  C(n) = A(j)
  n = n + 1
  j = j + 1
END WHILE

→ 条件为真时反复执行 · 用 END WHILE 收尾

定次循环 · FOR ... NEXT

FOR j = 0 TO len(a) - 1
  IF a[j] == t[j] THEN
    num = num + 1
  END IF
NEXT j

→ 含头含尾（0 到 len(a)-1 共 len(a) 次）
→ 用 NEXT j 收尾，表示 j 循环结束

3️⃣ 倒序循环 · STEP -1（学生最大难点）

FOR j = len(a) - 1 TO 0 STEP -1
  t = t + a[j]
NEXT j

含义：从 len(a)-1 开始，每次减 1，到 0 结束

例：a = "BANANAS"（长度 7），j 取 6, 5, 4, 3, 2, 1, 0

陷阱：Python 用 range(len(a)-1, -1, -1)，但 ACSL 直接写 TO 0 STEP -1，更直观
第 1 章 · 续

数组和字符串 · Arrays & Strings

ACSL 的索引语法容易踩坑

数组 · Arrays

A(0) = 12
A(1) = 41
A(2) = 52
print(A(0))  → 12

⚠️ ACSL 用 A(0)（圆括号）
而 Python 用 A[0]（方括号）
含义相同，别看花眼

字符串切片 · Substring（ACSL 特有）

S = "ACSL WDTPD"
S[:3]   = "ACS"     ← 前 3 个字符
S[4:]   = "DTPD"    ← 后 4 个字符
S[2:6]  = "SL WD"   ← 位置 2 到 6
S[0]    = "A"       ← 单个字符

⚠️ 字符串索引从 0 开始（不是 1）
⚠️ S[2:6] 含头不含尾（取位置 2, 3, 4, 5）

💡 字符串拼接：用 + 符号（如 t = t + a[j]）

第 2 章 · 方法论

分支追踪 · 3 步法

3 步搞定任何分支追踪题

第 1 步 · 通读代码找变量

先标出所有被赋值的变量（看到 x = ... 就圈出来）

→ 一般 2-5 个变量

第 2 步 · 画追踪表

每行 = 一个变量的当前值，每列 = 一个分支节点

→ 不要在脑子里算！写在纸上！

第 3 步 · 逐 if 顺序执行

ACSL 的 if 是连续 if 串联（不是 if-else 互斥）

→ 每个 if 都要判断，条件满足才执行

⚠️ 关键陷阱

一个变量可能被多次修改（如 h 从 50 → 48 → 40）

→ 每行只记"当前值"，不记"原值"

第 2 章 · 例题

例题 · 工资计算 ACSL Wiki Sample 1

ACSL Wiki 真题 · 第一次接触"业务逻辑追踪"

INPUT h, r
b = 0
IF h > 48 THEN
  b = b + (h - 48) * 2 * r
  h = 48
END IF
IF h > 40 THEN
  b = b + (h - 40) * (3/2) * r
  h = 40
END IF
b = b + h * r
OUTPUT b

问：输入 h = 50, r = 10，输出 b 是多少？

🤔 先自己想 30 秒再往下看

提示：这是一个计算员工周薪的程序

  • ≤ 40 小时：按 r 元/小时 算
  • 40-48 小时：1.5 倍工资（加班费）
  • > 48 小时：2 倍工资（双倍加班费）
第 2 章 · 详解

追踪表 · b 从 0 到 560

每行 = 执行完一个 IF 或最后一行后的状态

初始值：h = 50, r = 10, b = 0

行号执行语句bh说明
3 b = 0 0 50 初始
5 b = b + (50-48) * 2 * 10 40 50 2 倍加班 2h
6 h = 48 40 48 h 被修改了
10 b = b + (48-40) * 1.5 * 10 160 48 1.5 倍加班 8h
11 h = 40 160 40 h 被修改了
14 b = b + 40 * 10 560 40 基础 40h
答案：b = 560
心算验证：2h × 2 × 10 + 8h × 1.5 × 10 + 40h × 10 = 40 + 120 + 400 = 560 ✓

a 的索引：a[0]="B", a[1]="A", a[2]="N", a[3]="A", a[4]="N", a[5]="A", a[6]="S"

第 3 章 · 重难点

倒序循环 · STEP -1

学生最大失分点之一

FOR j = 5 TO 1 STEP -1
  PRINT j
NEXT j

输出：

j输出
55
44
33
22
11
⚠️ STEP -1 不是「0 到 5」，而是「5 到 1」！
起点在 = 前面，终点在 = 后面，STEP -1 表示每次减 1

陷阱 · 边界值

FOR j = 0 TO 0 STEP -1
  PRINT j
NEXT j

输出：0（只跑一次）—— 因为 0 到 0 已经相等，但 STEP -1 还要再判断一次条件

→ ACSL 边界值题常考，先画表再写答案

第 4 章 · 方法论

数组追踪 · 3 种常见模式

模式 1 · 单数组累加

A(0) = 10; A(1) = 20; A(2) = 30
sum = 0
FOR j = 0 TO 2
  sum = sum + A(j)
NEXT j

追踪表：

jA(j)sum
初始—0
01010
12030
23060

模式 2 · 哨兵值退出

A(0) = 5; A(1) = 8; A(2) = -1
sum = 0; j = 0
WHILE A(j) > 0
  sum = sum + A(j)
  j = j + 1
END WHILE

→ 当 A(j) = -1 时退出循环（哨兵值）

→ 输出 sum = 13

💡 哨兵值是数组末尾的特殊值（如 -1, 0, 空字符串），用来标记循环结束 —— OJ 学生完全没见过这个模式
第 4 章 · 重难点

嵌套循环追踪 · ACSL Wiki Sample 3

ACSL 第三轮真题 · 学生最大难关

A(0)=12; A(1)=41; A(2)=52
A(3)=57; A(4)=77; A(5)=-100
B(0)=17; B(1)=34; B(2)=81
j=0; k=0; n=0
WHILE A(k) > 0
  WHILE B(k) <= A(j)
    C(n) = B(k)
    n = n + 1
    k = k + 1
  END WHILE
  C(n) = A(j)
  n = n + 1
  j = j + 1
END WHILE
C(n) = B(k)
⚠️ 本程序本质：把两个有序数组合并成一个有序数组（归并算法 merge）
学生 OJ 上完全没练过这种"哨兵 + 双指针 + 嵌套 while"组合

问：执行后 C(4) 的值是多少？

追踪表 · 6 列变量

每次进入 / 退出内循环都记一行
